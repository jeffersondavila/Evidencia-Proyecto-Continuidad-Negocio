# Evidencia – Proyecto de Continuidad del Negocio (Fase 0 / Punto 0)

Este repositorio contiene la **evidencia documental** del proyecto académico de **Continuidad del Negocio**, específicamente el entregable **Fase 0 / Punto 0**, desarrollado bajo el marco de referencia de:

- **ISO 22301:2019** (Sistema de Gestión de Continuidad del Negocio)
- **ISO/IEC 27001:2022** (Sistema de Gestión de Seguridad de la Información)

> Nota: Este repositorio se utiliza para **control de versiones** y **trazabilidad** de la información documentada (diagramas y evidencias asociadas).

---

## Alcance de la evidencia (Fase 0 / Punto 0)

La Fase 0 documenta:
- **Organigrama** de la organización (según entregable del curso).
- **Identificación de 4 procesos críticos**.
- **Diagramas de proceso** por cada proceso crítico (con carriles), incluyendo:
  - Departamentos involucrados
  - Descripción del proceso
  - Evidencias/artefactos asociados (entradas, salidas, registros)
